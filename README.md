# OposIA

Plataforma de apoyo al estudio para opositores.

## Funcionalidades principales

- Temario de estudio.
- Análisis de exámenes.
- Chatbot con inteligencia artificial.
- Registro e inicio de sesión de usuarios.
- Acceso a fuentes públicas de exámenes.

## Tecnologías previstas

### Frontend
- React
- TypeScript

### Backend
- Node.js
- Express
- TypeScript

### Base de datos
- PostgreSQL
- Prisma ORM

## Estructura del proyecto

- frontend/: interfaz de usuario.
- backend/: lógica del servidor y API.
- docs/: documentación del proyecto.

## Estado actual

Configuración inicial del repositorio y estructura de carpetas.
